## Dirac notation tricks

A few definitions before we begin:
- **projector** $P$ is a matrix, s.t. $P^2=P$, equivalently eigenvalues $\lambda \in \{0; 1\}$, equivalently $P = \sum_i \ketbra{\psi_i}{\psi_i}$;
- **unitary** $U$ is a matrix, s.t. $U^\dagger U = I$.

Now we can use dirac notation, for example, to prove no-cloning theorem. From unitary definition we can see that unitary preserves inner product between two states: $\bra{\psi}U^\dagger U \ket{\phi} = \braket{\psi}I{\phi} = \braket{\psi}{\phi}$. When proving no-cloning theorem we can just pick two different states and apply the same unitary, that is assumed to have the cloning property.

Let's briefly see via a few examples, how a simple projector works on a state.

$P \ket\psi = \ketbra{1}{1} (\frac{1}{2} \ket0 + \frac{\sqrt3}{2} \ket1) = \frac{1}{2} \ket1\braket{1}{0} + \frac{\sqrt3}{2} \ket1\braket{1}{1} = \frac{1}{2} \ket1 \cdot 0 + \frac{\sqrt3}{2} \ket1 \cdot 1 = \frac{\sqrt3}{2} \ket1$.

Here we see that in essence we just "took" the term from our state, that corresponds to the projector. However, that holds only for when the state is written in orthogonal basis. We can see that with an example:

$P \ket\psi = 5\ketbra{0}{0} (\frac{1}{2} \ket0 + \frac{\sqrt3}{2} \ket+) = 5\ketbra{0}{0} (\frac{1}{2} \ket0 + \frac{\sqrt3}{2} \cdot \frac{1}{\sqrt2}(\ket0 + \ket1)) = 5\ketbra{0}{0} (\frac{\sqrt6}{2\sqrt2} \ket0 + \frac{\sqrt3}{2\sqrt2} \ket1) = 5 \cdot \frac{\sqrt6}{2\sqrt2} \ket0$.

And, of course, this can be extended linearly, so that you wouldn't need to expand the parenthesis every time, and just look where $\bra\psi$ corresponds to $\ket\psi$.

## Measurements and trace

A few definitions before we begin:
- **hermitian** $H$ is a matrix, s.t. $H^\dagger = H$ (which means $M = HH^\dagger$ is automatically hermitian, has real eigenvalues),
- **orthogonal** $M$ is real unitary,
- **normal** $A$ is a matrix, s.t. $A^\dagger A = AA^\dagger$ (equivalently is unitarily diagonazible $A = UDU^{-1}$ and has spectral/eigen decomposition $\sum_i \lambda_i \ketbra{\lambda_i}{\lambda_i}$),
- **PSD (positive semi definite)** $P$ is a matrix, s.t. $P$ is hermitian and all it's eigenvalues are non-negative (equivalently $\forall \ket\psi. \bra\psi P \ket\psi \geqslant 0$),
- **trace** of a matrix $M$ is a sum of its diagonal entries (equivalently the sum of its eigenvalues, for any orthonormal basis $\{\ket n\}$ (complete, i.e. $\sum_n \ket n \bra n = I$), $Tr(M) = \sum_n \bra n M \ket n$); also has a nice cyclic property $Tr(ABC) = Tr(BCA)$.

Djordjevic mentions 3 types of measurements: generalized, POVM, projective. In BQC book there's also a mention of a weak measurement but we don't analyze it here. Also, for now we are only talking about 1 qubit systems, that is don't include partial traces in the measurements. However, we talk about both **pure states** and **mixed states** (convex combination of pure states, or to be more precise - PSD operators of trace 1).

For any type of quantum measurement we have:
1. a set of outcome symbols;
2. a set of measurement operators $\{M_i\}$, one for each outcome.

For projective measurements (that are _supposedly_ the ones mentioned in QM postules) outcomes are selected from an **observable** by looking at it's eigenvalues (because of that for degenerate cases, with the same eigenvalues on multiple orthogonal eigenvectors, we would need to sum up those probabilities). Observable examples: momentum $\hat p$, energy/hamiltonian $\hat H$, computational basis $Z$.

**Generalized measurement** is of the Kraus representation form (not discussed in this post) and is the most general way to represent a measurement. The only restriction for measurement operators is completeness $\sum_i M^\dagger M = I$ (probabilities sum to 1).

_For pure state $\ket\psi$._

Probability to measure $m$: $p_m = \bra\psi M\dagger_m M_m \ket\psi$.

Final state after measuring $m$: $\ket{\psi_f} = \dfrac{M_m \ket\psi}{\sqrt{p_m}}$.

_For mixed state $\rho$._

Probability to measure $m$: $p_m = Tr(M_m \rho M^\dagger_m)$.

Final state after measuring $m$: $\rho_f = \dfrac{M_m \rho \M^\dagger_m}{p_m}$.

**POVM (positive operator valued matrix)** is the generalized measurement defined differently, using PSD operators $\{E_m\}$. That is, POVM operators are PSD and can just replace $M^\dagger M$ in generalized measurement.

_For pure state $\ket\psi$._

Probability to measure $m$: $p_m = \bra\psi E_m \ket\psi$.

Final state after measuring $m$: $\ket{\psi_f} = \dfrac{M_m \ket\psi}{\sqrt{p_m}}$.

_For mixed state $\rho$._

Probability to measure $m$: $p_m = Tr(M_m \rho M^\dagger_m)$.

Final state after measuring $m$: _without explitic configuration of Kraus operators - not possible to say_.

**Projective** measurement is POVM, of which measurement operators are projectors.

But we are mostly focusing on POVM, for which it's important to remember two conditions:

1. $\forall m. \bra\psi E_m \ket\psi \geqslant 0$,
2. $\sum_i E_m = I$.

Explicit calculation examples will not be given here, but inspiration can be found above, in the dirac tricks' section. And another 2 examples would be simply worded like this below.

We can have a state $\ket+$ which then can be measured with a basis measurement (projective measurement) in these two example ways:
1. on $Z$ (computational $\ket 1$, $\ket 0$) bases, finding probabilities of resulting eigenvector/base states with eigenvalues $\pm 1$, giving 50/50 probability;
2. on $X$ basis ($\ket +$, $\ket -$), giving 100/0 probability for resulting $\ket +$ state.

This corresponds to the physical system property of being able to be measured over different obnservables, measuring different metrics.

## Partial trace

Partial trace is used when measuring part of a composite system, e.g. only A of AB. But this is left for the future. Here we just overview some properties that can be used in UvA QC Chapter 1 exercises.

Partial trace definition is this (for orthonormal basis $\{\ket i\}$):

$Tr_B (\rho_{AB}) = \sum_i (I \otimes \bra i) \rho_{AB} (I \otimes \ket i)$.

But it might be confusing, so I would suggest remembering this one with separable state:

$Tr_B (A \otimes B) = A \otimes Tr(B)$ (and since states are trace 1, it just becomes $A$).

Or if calculating it with explicit 4x4 matrices:

for

$$
  \rho_{\mathcal{AB}}
  = \left[
    \begin{array}{c|c}
      P & Q
    \\\hline
      R & S
    \end{array}
  \right]
$$

it becomes

$$
  \begin{aligned}
    \rho_{\mathcal{A}}
    &=
    \tr_{\mathcal{B}}\rho_{\mathcal{AB}}
    = \left[
      \begin{array}{c|c}
        \tr P & \tr Q
      \\\hline
        \tr R & \tr S
      \end{array}
    \right]
  \\\rho_{\mathcal{B}}
    &= \tr_{\mathcal{A}}\rho_{\mathcal{AB}}
    = P+S.
  \end{aligned}
$$

But especially useful is this one partial trace property (that can be used in Ex 13 a), I call it the "ignore the I inside" rule):

$Tr[M_{AB}(X_A \otimes I_B)] = Tr[Tr_B[M_{AB}]X_A]$.

## Decompositions

Spectral (eigen) decomposition - for a normal matrix (hermitian, PSD, unitary included):

$H = \sum_i \lambda_i \ketbra{\lambda_i}{\lambda_i}$, here lambdas are eigenvalues and eigenvectors.

SVD (singular value decomposition) - for any matrix:

$M = \sum_i s_i \ket u \bra v$, here $s_i = \sqrt{\lambda_i}$.

Relationship between them can be informally demonstrated with this example:

$M^\dagger M = H = \sum s_i s_j \ket{h_i} \braket{k_i}{k_i} \bra{h_i} = \sum \lambda_i \ketbra{h_i}{k_i}$.

## Honorable mentions

1. Transpose trick for maximally entangled states (e.g. EPR pairs) is useful in Ex14 (b):

$(M \otimes I) \ket{\Psi^+} = (I \otimes M^T) \ket{\Psi^+}$.

2. Pauli matrices have this cyclic property:

$XY = iZ$, $YZ = iX$, $ZX = iY$;

and squared become $I$.
